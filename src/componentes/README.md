# src/componentes

Um arquivo `.jsx` por componente reusável, com o nome do layout que ele
implementa quando houver um: `TabelaDeSessao.jsx` (LG-25), `Anotacao.jsx`
(LG-26), `MapaDeSessoes.jsx` (LG-30).

Componente aqui não conhece protocolo. Ele recebe dados por prop e desenha; o
que muda de hipertrofia para dieta é o conteúdo e o acento, e nenhum dos dois
entra em `if`.

Vazio de propósito: nenhuma sessão foi desenvolvida ainda.
